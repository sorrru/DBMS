## 人工问题与修复记录

### M10-MANUAL-01：退出后残留发布成功消息

- 复现：发布问卷成功后点击“退出登录”；
- 预期：登录表单不显示上一登录会话的工作区消息；
- 实际：密码输入框下方仍显示“版本发布成功。”；
- 根因：`App.vue` 的 `message` 是登录与工作区共用的内存状态；发布成功会写入该状态，而成功注销路径只清除了用户、列表、页面和模式，没有清除 `message`。同类 `publishError` 也缺少会话边界清理；
- 失败测试：新增退出状态转换测试，修复前稳定收到 `expected '版本发布成功。' to be ''`；
- 修复：注销 API 成功后调用 `resetFeedbackAfterSignOut()`，同时清空通用消息和发布错误；注销 API 失败仍保留真实错误；
- 定向复测：新测试通过，Web 7 个文件、23 项测试全部通过；
- 完整回归：共享逻辑 11 + API 144 + Web 23，共 178 项全部通过；根类型检查、生产构建和格式检查通过；
- 人工状态：2026-10-21 项目负责人重新执行原路径，确认登录页不再出现旧消息，复测通过。

### M10-MANUAL-02：填写页缺少明确的账号退出与切换入口

- 复现：登录填写者账号进入公开问卷；禁止重复的版本已提交时，页面只显示业务错误和“开始填写”，没有当前账号、退出登录或切换账号入口；
- 预期：页面明确显示当前账号；可退出登录；已提交时不能再次开始，并能直接切换账号；活动会话退出前解释本地草稿与同账号恢复边界；
- 修改：填写页头部增加当前账号和“退出登录”；`ALREADY_SUBMITTED` 后禁用开始按钮并显示“该账号已提交”和“切换账号填写”；活动会话退出前立即保存防抖草稿并二次确认，成功注销后进入登录页且保留安全站内返回路径；
- 安全补充：换账号恢复旧会话收到 `SESSION_NOT_FOUND` 时，按 sessionId 清除该会话的全部本地草稿，避免共享电脑残留；窄屏下账号栏改为纵向排列；
- 自动检查：新增活动会话返回路径、退出提示、已提交控件和会话级草稿清理测试；共享逻辑 11、API 144、Web 26，共 181 项全部通过，类型检查、生产构建和格式检查通过；
- 人工状态：2026-10-21 项目负责人确认当前账号、已提交禁用、切换账号、活动会话退出确认、同账号恢复和异账号拒绝均通过。

### M10-MANUAL-03：实名版本无文本回答时看不到填写账号

- 复现：实名版本已有正式提交，但填写者没有回答文本题；既有账号信息只附着在文本回答分页，创建者统计页无法查看填写者；
- 预期：实名版本无论是否包含或回答文本题，都能查看每次正式提交的账号和时间；允许重复时保留同账号的多条记录；匿名版本不得暴露该入口或接口；
- 修改：增加按版本索引倒序分页的 `/submissions` 创建者接口，批量补全用户并使用绑定问卷、版本和专用 kind 的 AES-256-GCM 游标；统计摘要增加 identityMode，前端只在实名版本底部自动显示“实名提交记录”；
- 隐私与性能：每页 20 条、最多 50 条；响应不含 response id、答案和内部身份键；匿名版本返回 `VALIDATION_ERROR`；三个统计读取接口共享限流、超时和 no-store；
- 自动检查：增加不依赖文本答案、重复账号逐次显示、分页、批量用户查询、匿名拒绝、越权、未知参数和游标绑定测试；同时修正原游标篡改测试对 Base64URL 尾部未使用位的偶发性。共享逻辑 11、API 147、Web 26，共 184 项全部通过，类型检查、生产构建和格式检查通过；
