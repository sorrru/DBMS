最初前端 SSR 三项分别验证：旧本地题仍可编辑并出现保存与选题入口；来源题定义禁用且提供显式换版本与转本地、标题纯文本转义；写入期间题目控件锁定。追加第四项验证设置或规则未保存时禁用常用题目操作，避免换实例时丢失未保存规则；普通本地编辑仍可继续。接口测试与 SSR 不能替代真实选择、点击和小屏布局检查。

## 设计与实现核对

- 问卷实例 questionId 保持原义，新增 source 不迁移旧答案。
- 快照中的来源 ID 是规范字符串，集合资源 ID 及使用记录引用为 ObjectId，投影层转换；库选项和问卷选项通过来源映射分离。
- 保存本地题入库不等于选入，不为旧数据自动建立统计关联；题目库版本初始可修改。
- 选入、换题、删除和转本地的使用记录按变更增删；排序和跳转不重复登记。
- 永久冻结与当前使用计数独立；放弃或删除最后引用不解冻。
- 共享撤销后的授权竞争和他人引用汇总留到里程碑 3，跨问卷回答聚合留到里程碑 5。
