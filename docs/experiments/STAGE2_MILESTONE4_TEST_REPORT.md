## 人工检查步骤

沿用已有账号与数据，运行 `npm run dev`（已运行时刷新页面）。无需额外配置或重置数据。

| 步骤 | 操作                                               | 预期                                                       |
| ---- | -------------------------------------------------- | ---------------------------------------------------------- |
| 1    | 登录，管理常用题目与版本 → 管理题库分类            | 显示题库管理；创建“基本信息”和“教学”                       |
| 2    | 在“基本信息”加入自己的年龄题，确认固定版本         | 显示标题及版本；未冻结时明确提示仍可原地修改               |
| 3    | 把同一题也加入“教学”，再重复加入同一库             | 跨库允许，同库重复给出冲突且不重复出现                     |
| 4    | 回常用题目创建年龄题新版本，再返回原题库           | 固定成员保持旧版本                                         |
| 5    | 点“更新到新版本 / 设置策略”，核对差异后确认        | 成员更新为明确选定版本；现有问卷保持旧快照                 |
| 6    | 切换“跟随最新可用版本”，再创建题目新版本并刷新题库 | 预览与当前可用版本一致，刷新后跟随新版本                   |
| 7    | 问卷草稿 → 从常用题目选入 → 按题库选择             | 按成员策略使用具体版本；固定历史版本不会变成最新           |
| 8    | 另一账号将共享题加入题库，源所有者创建未共享新版本 | 接收者的 latest 仍只显示最高获授权版本                     |
| 9    | 固定某共享版本后撤销该版本授权                     | 该成员显示不可用；可以移出，不自动换版本；已有问卷快照保留 |
| 10   | 改名、移出成员、删除题库                           | 分类变化，常用题目及问卷仍存在，已冻结版本不会解冻         |

本里程碑等待用户逐项检查和确认。跨问卷统计属于里程碑 5，此轮未实现。
