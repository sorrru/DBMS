## 实现与口径

统计自己的已发布问卷（含历史版本）中，同一常用题目身份的来源实例。默认各版本独立，可核对差异后明确合并。选择题以源选项 ID 合并；数字给出计数、总和、平均、极值和自定义分桶；文本支持加密分页。重复实例分别计数，不把实例量叫人数，草稿排除。

仅当前用户拥有的问卷可贡献回答；共享、题目所有权与他人使用汇总均不授予他人回答访问权。接收者在撤销共享后保有自己问卷快照的统计权。文本仅输出内容、UTC 日期和题目版本，不给出账号、响应 ID 或精确时间。

来源和回答在一次 snapshot 事务内读取；每批最多 50 实例，responses 用 surveyVersionId 索引过滤后展开，无回答 lookup。每身份最多 1000 发布引用、每次最多 50 所选版本；超限报错，不静默给出部分“总体”。

## 自动检查

新增 API 15 项集成，覆盖：多问卷多版本年龄手算与边界；同提交重复实例、未到达与到达未答；稳定源选项和改名；多选比例；无回答与有效 0；共享与撤销权限；伪造冗余投影不得越权；排除草稿；同时间文本多实例分页、加密及条件绑定；非法请求；HTTP 认证、Origin 与缓存；跨批 snapshot 并发新增；真实索引 explain；同文不同 ID 选项不得合并；大小写及符号实例 ID 的文本分页排序。

新增 Web 5 项，覆盖默认折叠且不自动读取回答、默认分版本及筛选清空旧结果和合并确认、桶边界校验、文本续页和请求契约。组件状态采用 Vue 自定义渲染器，静态页用 SSR；未声称完整浏览器端到端或已完成人工验收。

## 人工检查步骤

沿用现有登录账号。运行 `npm run dev`；若已运行，刷新即可。可以在常用题目详情，或自己草稿/已发布问卷的来源题位置点击“跨问卷统计”。

| 步骤 | 操作                                                  | 预期                                                                      |
| ---- | ----------------------------------------------------- | ------------------------------------------------------------------------- |
| 1    | 把同一年龄题选入两份问卷并发布，分别填写 18、30 与 60 | 默认同版本总体 count=3、sum=108、average=36、min=18、max=60               |
| 2    | 查看默认年龄桶                                        | 18 在 [18,30)，30 在 [30,45)，60 在 [60,120)，其余桶 0                    |
| 3    | 边界改成 0,20,40,80，再改成 20,0                      | 合法边界重新分桶；逆序边界在发送前提示，不显示旧结果                      |
| 4    | 在一份问卷重复加入该题并提交两次答案                  | 两个实例分别计入，机会数和回答数按实例增长，说明不称为人数                |
| 5    | 创建该题新版本并用于另一份已发布问卷，填写一个值      | 默认分别显示两个版本；草稿没有统计来源                                    |
| 6    | 勾选“合并所选版本”                                    | 展示差异，未确认不能查询；勾选确认后提供总体                              |
| 7    | 修改版本筛选或边界                                    | 原结果和合并确认清空，须按新口径重查                                      |
| 8    | 对单选/多选题跨问卷统计；同身份版本改名选项           | 同源 ID 的计数合并，文字变化保留；多选比例以已答实例为分母                |
| 9    | 对可选题提交跳过或未答数据；对数字题填写 0            | 到达未答与未到达分别显示；0 参与数字计数，空数据极值和平均为“无”          |
| 10   | 使用文本题，填写超过 20 个实例回答，点更多            | 不漏不重复，保留题目版本和日期；不显示账号或精确时间，HTML 内容按文字显示 |
| 11   | 第二个账号在自己的问卷使用共享题并填写                | 源所有者的统计不包含第二账号回答；第二账号仅统计自己的问卷                |
| 12   | 撤销共享后，从接收者已发布问卷来源题打开统计          | 自己已提交的回答仍可统计；题库读取和新的选入仍被拒绝                      |

等待用户人工检查确认，之后才进入里程碑 6。
