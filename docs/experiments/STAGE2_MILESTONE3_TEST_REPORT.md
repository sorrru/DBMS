## 数据和边界

新增 question_shares，以用户与具体版本为授权单位。接收者读取通过授权范围过滤，父版本及身份元数据经过脱敏；修改原题仍走原所有者检查。使用和撤销通过同一授权文档的条件写入与删除争用，保留旧快照且拒绝后续新采用。

自己的引用明细核对真实问卷所有者及快照来源后返回；他人汇总以事务维护的 usages 投影为数据源，仅源题所有者可读。投影核对与修复工具按既定清单在最终回归里程碑整理。已有按问卷版本统计权限不变，本里程碑不提供跨问卷回答聚合。

授权管理仍能间接发现注册账号是否存在；本轮按已确认方案以统一受理和限流降低风险，不将其描述成完全避免账号枚举。
