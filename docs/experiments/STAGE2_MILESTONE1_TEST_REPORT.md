## 前端自动检查与自查修复

四项新增前端测试分别验证：响应式版本可转换为独立可编辑表单；差异内容安全转义并识别选项身份变化；原地修改、派生和恢复使用不同请求契约；数字限制差异使用可读标签。

自查发现 `structuredClone` 不能直接复制 Vue 的 Proxy，可能导致从查看模式点击编辑失败。改为按字段构造表单副本，复制 validation 与选项，加入使用 `reactive` 对象的回归测试，确认表单修改不污染查看基线。修复后 Web 30 项、类型检查和生产构建通过。

SSR 和接口测试不能代替真实点击验收；本轮未启动网站或代用户填写人工确认。
