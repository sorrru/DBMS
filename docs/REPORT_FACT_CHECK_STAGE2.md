## 5. 关键语义复核

- questionId 始终为问卷实例，libraryQuestionId 和 questionVersionId 分别为库身份与版本。
- source 保存 String 资源 ID 与源选项映射，资源及 usages 对应字段使用 ObjectId；服务端构造，公开填写去掉 source。
- 原地修改须未冻结且 contentRevision 匹配；已被草稿/发布采用、复制或派生的版本永久冻结。
- 恢复生成新版本并记录来源，不覆盖旧版本；当前优先为已确认 UI 默认，不写成后端全部历史操作删除。
- 共享按版本，现有界面共享当前版；接收者只看到授权范围，新版本不自动共享。
- 撤销阻止未来库访问/采用，原快照继续；题目作者无权读接收者回答。
- 使用数量按实例；他人只 username/versionNumber/status/count，不给问卷名/回答。
- 题库 latest 为最新可访问；pinned 失效不回退，也不自动冻结未用定义。
- 跨问卷只读自己发布来源，默认分版本，可确认合并；数字桶包括上下界外，不逐值返回年龄频数。
- 一次请求 snapshot 贯穿来源与批次，文本下一页另建视图；游标密钥派生加密且条件绑定。
- 定向修复会写父问卷 updatedAt，可能改变列表排序，不改发布定义、回答和冻结；clean 无写入。
